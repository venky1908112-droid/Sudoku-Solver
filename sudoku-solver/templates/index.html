How It Works

The solver keeps a set of used digits for every row, column and 3×3 box, plus a list of empty cells. For each empty cell it computes candidates = {1..9} − row − column − box, places one, updates the sets and recurses to the next empty cell. If the recursion fails, it undoes the sets and the cell and tries the next candidate (backtracking). Every placement and undo is recorded as an event; this page replays that event log.

Time: worst case exponential, O(9k) for k empty cells; space: O(k) recursion depth plus the 27 sets.
